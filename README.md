## Run Locally

This is a static website and does not require a build process.

1. Download or clone this repository.
2. Open `index.html` in a browser.

Alternatively, start a local web server from the project folder:

    python -m http.server 8000

Then open [http://localhost:8000](http://localhost:8000).

## Deploy

The portfolio can be hosted using GitHub Pages:

1. Open the repository on GitHub and go to **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select the branch containing the portfolio files and the `/ (root)` folder.
4. Save. GitHub Pages will provide a link to the published site.
